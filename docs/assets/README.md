# Visual assets

The README header and console favicon use the StructureML mark, `structureml-mark.svg`, as
published at [structureml.com](https://structureml.com/favicon.svg). Keep its paper tile, ink, and
terracotta link as supplied. The console header uses a single-colour copy in `logos.js`.

The setup console uses vendor marks to identify integrations. Source categories are recorded in
`src/paid_media_agent/admin/static/logos.js`:

- [Simple Icons](https://simpleicons.org/) supplies the monochrome marks identified there, under CC0.
- Deep Agents, LangSmith (the LangChain mark), Google, Meta, LinkedIn, Reddit, X, and BigQuery use official brand or product marks.
- Pipeboard uses its public favicon; Groq and Zhipu use letter tiles.

The self-hosted image downloads IBM Plex Sans and Mono 1.1.0 from IBM's releases, pinned by
checksum and shipped with their SIL Open Font License, so PDF reports embed the brand fonts.

Keep vendor marks consistent with their owners' branding. The repository's Apache-2.0 license
covers project code and does not grant rights to vendor trademarks.

The README compositions and report illustration under `docs/screenshots/` show example data.
Update them when the visible product changes; do not include live account data or credentials.
